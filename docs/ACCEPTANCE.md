# 完整组件对照验收

当前范围是18种现行 Mushroom v5.2.3 卡片、Template Badge 与全部11种Chips。Chips Card 本身属于18卡，其子类型另列11项；Legacy Template单列兼容，不计数。原23家庭场景展示不是本轮验收清单。

页面必须区分三类证据：
1. 固定版本官方文档静态图：仅证明官方样例外观，不证明相同实体/状态运行。
2. 真实隔离 HA 运行截图：注明HA版本、配置、合成状态、容器和提交；原版与fork同条件捕获。
3. 未运行/缺少样例：明确显示缺失，不绘制近似原版冒充。

功能源码、服务调用、模板订阅、配置schema、编辑器和尺寸公式复用固定上游。构建清单证明源码与命名转换，但不能代替实际浏览器和HA验证。

应检查：每类配置与默认值、控件显示条件、tap/hold/double-tap、独立图标动作、条件Chips规则、菜单/Quickbar/Assist、Jinja更新和解绑、编辑器配置事件、实体不可用和服务错误、Sections/Masonry尺寸、窄容器及固定行高、明暗主题与键盘可达性。
